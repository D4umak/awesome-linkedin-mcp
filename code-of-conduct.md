# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, and remember that PRs are about the list — not the people submitting them.

Report issues to [john@johnpeslar.com](mailto:john@johnpeslar.com).
