# Contributing to awesome-linkedin-mcp

Thanks for wanting to add to the list. Keep it simple:

## What belongs here

- LinkedIn MCP servers — open source or commercial
- Workflows that use a LinkedIn MCP in Claude Code, Codex, or a similar agent harness
- Adjacent MCP servers commonly stacked with a LinkedIn MCP
- Resources, docs, and community projects

## What doesn't

- Closed/dead projects
- Tools that don't actually use MCP (e.g. browser extensions, standalone web apps)
- Affiliate spam or self-promotion without substance

## How to submit

1. Fork the repo
2. Add your entry alphabetically within its section
3. Use this format: `- [Project name](URL) — One-line description focused on what it does, not who built it.`
4. Open a PR with a short note about why it belongs

## Quality bar

Entries should have:
- A working link
- A clear one-line description
- Active maintenance (commits in the last 12 months for OSS) OR a public commercial product
- A README that explains setup

If you're maintaining a LinkedIn MCP, please be honest about ToS risk in your project's own README — it helps users make informed choices.

That's it. PRs usually merge within a few days.
